AI-Lover 快速使用说明
版本：2.0.1

一、最简单的启动方式

1. 先把整个 zip 压缩包解压出来。
   注意：不要只复制 AI-Lover.exe，必须保留 app、runtime、docs 等文件夹。
2. 双击 AI-Lover.exe。
3. 等 10-30 秒，浏览器会自动打开：
   http://127.0.0.1:3000/
4. 点击网页右上角“开始”，即可开始对话。
5. 需要停止时，双击 Stop_AI-Lover.bat。

二、可选安装方式

1. 双击 Install_AI-Lover.bat。
2. 程序会安装到：
   %LOCALAPPDATA%\AI-Lover
3. 桌面会生成 AI-Lover 快捷方式，以后双击桌面图标启动。

三、连接机器人头部

1. 电脑和机器人头部必须在同一个局域网。
2. 头部 IP 可在网页“设置”里修改，也可以改：
   app\customer_config.ps1
3. 头部测试页：
   http://127.0.0.1:3000/head-control
4. 在测试页里依次点：
   启动/重连头部桥接 -> 检测 -> 测试音箱 -> 测试麦克风。
5. 测试麦克风时页面会显示波形图；没有波形说明头部麦克风或 ADB 采集链路还没通。
6. 如果测试音箱有声音，但对话时头不发声，检查首页“头部音量”不是 0。

四、连接 Arduino 手和 ORCA 手

1. 机械手测试页：
   http://127.0.0.1:3000/hand-control
2. 点击“检测”查看串口提示。
3. CH340/WCH/Arduino/CP210/FTDI 通常是 Arduino 手。
4. Dynamixel/U2D2/Robotis/ORCA 通常是 ORCA 手。
5. 只测试识别时保持 Dry-run。
6. 要真实控制机械手时关闭 Dry-run。
7. Arduino 手可用“张开/握拳/食指”等按钮测试。
8. Arduino 手还可以测试“演示模式”和“演奏模式”。
9. ORCA 手先用 17 关节滑杆逐个小幅测试，再开启手势跟随。

五、手势骨架和粒子效果

1. 首页摄像头区域会显示手部骨架。
2. 设置里可开启“比心粒子特效”。
3. 单手比心会飘出爱心。
4. 双手比心会飘出爱心，并从屏幕上方落下铜钱。
5. 张开手掌会出现闪光粒子。
6. 握拳会出现脉冲光环。

六、画面交换和眼球追踪

1. 桌面横屏：双击左上数字人或左下摄像头，可切到右侧大画面。
2. 桌面横屏：双击右侧大画面，可返回对话画面。
3. 手机竖屏：点击主画面或右上小窗，可交换数字人和摄像头大小。
4. 眼球追踪：在设置的“硅胶头机械芯”里开启“眼球追踪外部摄像头中的人脸”。
5. 如方向相反，开启“眼球追踪反向”；需要脖子也跟随时，再开启“脖子跟随大幅度方向”。

七、手机、Mac、其他电脑访问

本机使用：
http://127.0.0.1:3000/

同一局域网里的手机、Mac 或另一台电脑访问时，请使用：
https://本机局域网IP:3443/

例如：
https://192.168.110.254:3443/

注意：局域网访问如果用普通 http://192.168.x.x:3000/，苹果电脑和手机可能无法打开摄像头和麦克风。请改用 HTTPS 地址。

八、热更新包

如果已经安装过完整包，只需要更新程序，可使用：
AI-Lover-2.0.1-hot-update.zip

使用方式：
1. 关闭 AI-Lover。
2. 解压热更新包。
3. 用热更新包里的 app 文件夹覆盖原来的 app 文件夹。
4. 重新启动 AI-Lover。

九、常见问题

1. 网页打不开：
   先双击 Stop_AI-Lover.bat，再重新双击 AI-Lover.exe。

2. 开始对话失败：
   检查云端服务 http://47.95.119.182:8080 是否可访问。

3. 头部能动但不发声：
   检查首页头部音量；打开 /head-control 测试音箱。

4. Arduino 手不动：
   检查 Dry-run 是否关闭、COM 口是否正确、机械手是否通电。

5. ORCA 手不动：
   检查 Dry-run 是否关闭、ORCA/Dynamixel 串口是否正确、扭矩是否开启。

十、发给技术支持的信息

遇到问题时，请发送：
- 启动窗口截图
- 网页错误截图
- 机器人头部 IP
- Arduino/ORCA 串口号
- %LOCALAPPDATA%\AI-Lover\local_logs 里的日志文件
