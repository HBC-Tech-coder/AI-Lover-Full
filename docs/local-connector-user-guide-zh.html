AI-Lover Local Connector 2.0.4 图文操作手册

给第一次使用的同事和客户看的说明：怎么启动、怎么连接云端、怎么离线测试头和手、多台 Arduino 手怎么填写，以及 GPU 数字人怎么接入。

最重要的一句话： 云端对话打开 https://ai.vituralmodel.com；现场调硬件、网络不好或断网时，先运行 START-HERE.bat，再打开 http://127.0.0.1:3000/local-control。

1. 两种工作模式

云端模式

打开 https://ai.vituralmodel.com 进行 AI 对话。云端网页通过 Local Connector 连接客户电脑里的仿生头、机械手和局域网 GPU 数字人服务。

需要互联网

本地离线控制台

打开 http://127.0.0.1:3000/local-control。它不做 AI 对话，但可以低延迟测试摄像头、手势骨架、粒子特效、仿生头和机械手。

断网也能用

2. 解压和启动

  1. 右键收到的 zip，选择“全部解压”。
  2. 不要只复制一个文件，必须保留整个解压目录。
  3. 进入解压目录，双击 START-HERE.bat。
  4. 等待 10 到 30 秒，浏览器会打开本地首页。
  5. 现场调硬件时，打开 http://127.0.0.1:3000/local-control。

4. 多台 Arduino 手

Local Connector 支持同时控制多个 Arduino 手。在 Arduino 串口输入框里填写多个 COM 号，用英文逗号分隔。

示例：COM5,COM6
含义：同一个手势命令会同时发送给 COM5 和 COM6。

不要使用中文逗号。真实控制硬件时，关闭 Dry-run，并打开“启用 Arduino 输出”。

5. 串口怎么判断

设备提示通常是什么应该填在哪里
CH340 / WCH / Arduino / CP210 / FTDIArduino 手Arduino 串口，可填多个，例如 COM5,COM6
U2D2 / Dynamixel / RobotisORCA 手ORCA / Dynamixel 串口，通常填一个
完全没有 COM 号驱动、USB 线或供电问题先检查设备管理器

6. 仿生头连接

  1. 电脑和仿生头连接同一个 Wi-Fi，或者使用 USB 调试。
  2. 填写头部 IP，例如 192.168.110.139。
  3. 点击“启动/重连头部 bridge”。
  4. 点击“检测”。
  5. 点击“喇叭”测试头部音箱，点击“麦克风”测试头部麦克风。

7. GPU 数字人

默认情况下，系统仍然使用 Live2D，CPU 也能运行。如果客户现场有局域网 GPU 主机，例如 4090，可以在设置里把 GPU worker 地址改成局域网服务地址：

http://192.168.110.50:8810

云端网页不能直接访问客户内网 IP。请先运行 Local Connector，再启用“云端 Local Connector”。这样云端网页会通过客户电脑转发到本地或局域网 GPU worker。

如果没有真正的 MuseTalk / SoulX-LiveAct worker，系统会自动启动本机预览 worker，用头像图验证流程，不会生成真实视频。

8. 云端配对 Local Connector

  1. 打开 https://ai.vituralmodel.com。
  2. 进入右上角设置。
  3. 找到“连接本地设备向导”。
  4. 勾选“启用云端 Local Connector”。
  5. 点击“生成”得到配对码。
  6. 把配对码输入 START-HERE.bat 的黑色窗口并回车。
  7. 回到网页点击“检测 Local Connector”。

9. 常见问题

骨架能识别，但机械手不动

检查 Dry-run 是否关闭、Arduino 输出是否开启、COM 号是否正确、外接电源是否打开。

云端显示头部异常或手部异常 502

Connector 已经连上云端，但本机头部 bridge 或机械手 bridge 没启动。打开本地离线控制台，点击启动/重连。

不要关闭黑色窗口

只要还在控制头和手，START-HERE.bat 的黑色窗口就必须保持运行。
